# 游戏作品集网页

## 打开方式

直接双击 `index.html`，用 Chrome / Edge 打开即可。视频使用相对路径，不需要联网。

如果浏览器限制本地视频播放，可以点击每个作品下方的 **“单独打开视频”**。

页面现在是 **纯黑底 + 红色强调**，去掉了首页背景图、颗粒纹理和大面积装饰文字，只保留作品截图与视频封面。

1. **署名**：页面写的是“黄昊轩”。
2. **项目文案**：Astro Bot 与卡牌游戏的分工、时间、卡牌数量，已按你的简历内容写入；如果和最终版本不一致，直接在 `index.html` 里搜索标题修改。

## 视频体积

网页当前使用的是新放入的压缩版视频，三支合计约 **74 MB**，其中《画中洞天》约 50 MB。页面用了 `preload="none"`，不会在打开页面时加载视频，只有点击播放才会读取。

旧的未压缩原文件仍保留在 `videos/` 里，但网页不再引用；确认新版播放正常后可以自行删除。

## 本地服务器（可选）

如果直接双击无法播放，或者你想在手机上预览，可以在当前目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
