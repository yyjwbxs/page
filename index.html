01精选项目

画中洞天

国风画境中的 2.5D 空间解谜 / 2026.07–09

实机演示 / 2026

《画中洞天》是一款使用 Unity 开发的 2.5D 空间解谜游戏。玩家操控小墨灵，在山水画构成的棋盘中移动、推动画片，并借助能够容纳内部世界的界箱改变运输路线，最终让缺失的画片回到对应位置。

我的工作以关卡策划为主，同时参与美术与程序落地：负责关卡逻辑设计，利用多重嵌套的空间逻辑构建关卡；参与 UI 设计与嵌套相关代码，并与程序、美术协作推进关卡落地。

02Roguelike 练习

Astro Bot

2D Roguelike 课程作业 / Unity / 2024.10–12

开发记录 / 2024

《Astro Bot》是一款 2D Roguelike 课程作业，3 人团队。我在项目中担任主策、主美与副程：在 Unity 搭建白盒、随机选项与敌人对象池生成，并对敌人刷新波次与数量进行模拟，确保难度曲线处于合理区间。

视频记录了关卡与系统在 Unity 编辑器中的搭建、调试过程。项目为课程作业，非商业作品。

03卡牌构筑

Roguelike 卡牌游戏

类《杀戮尖塔》/ 主策 · 主程 / Unity / 2025.10–12

实机录像 / 2025

以《杀戮尖塔》为参考的卡牌构筑 Roguelike，3 人团队。我在项目中担任主策与主程：搭建“探索—战斗—掉落—构筑”核心循环，设计 1 张大地图、32 张卡牌、24 种敌人与 10 个事件，形成 2 种可行流派。

同时作为客户端加入联网功能，支持多人同时进行游戏。视频为实机对战录像。
